# Storyliner sits under the Intellectual Resistance umbrella

Storyliner is one project under **intellectualresistance.com** (the umbrella over a set of evidence-first reasoning frameworks; shares house language with it-help.tech, dnstool, organiccomputer). The site's voice: a strict academic professor — "thinking that shows its work," logic/reason, gold-on-near-black, mono labels.

# Taste rules for the top brand strip (`home.tsx` top strip) — learned from the user

- **The page is NOT anti-AI**, but it is a strict, academic, intellectually serious tool. Don't frame AI negatively.
- **Never put a price on it** — not even "free." The user finds "free coach" cheapening; the value should read as "priceless" and users should infer it. No "AI soon" / status badges either.
- That top-right slot is **prime real estate**: it now holds a subtle mono link **"A project of intellectual resistance" → https://intellectualresistance.com** (ArrowUpRight icon), not an app-status badge.

# The mission: teach organic-first thinking (the "resistance")

The point of Storyliner (per the user) is to teach **real, organic strategy** so a brand thinks correctly *before* it ever reaches for paid ads or a "shitty SEO company." The enemy is paying-to-cheat; the resistance is understanding the method. So copy/features should keep showing the *why* (the reasoning behind honest discovery), favor organic levers over paid/gimmick ones, and never imply you must buy your way to visibility. This is the throughline of the whole Intellectual Resistance umbrella.
